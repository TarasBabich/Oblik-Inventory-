# Oblik Inventory

Desktop-програма для обліку необоротних активів і запасів з Excel-сумісною структурою.

## Поточна версія 0.2.6 — Flet

Інтерфейс повністю переведено з PySide6 на **Flet 1.x**. Бізнес-логіка Excel, pandas і openpyxl збережена. У 0.2.3 виправлено несумісні назви кольорів Flet 1.x (`WHITE_24`, `WHITE_70`).

Реалізовано:
- відкриття існуючих `.xlsx/.xlsm` книг;
- створення нової книги з 5 аркушами;
- розділи `Штат`, `Рух майна`, `Поточний стан`, `Зведений`, `Контроль змін`;
- додавання, редагування і видалення записів `Рух майна`;
- пошук по відкритій таблиці;
- контроль дублювання 5/5, 4/5, 3/5 без жорсткого блокування;
- автоматичний журнал `Контроль змін`;
- автоматичне формування `Поточний стан` для поштучного майна;
- `№ з/п` приховано в інтерфейсі, а в Excel використовується формула `=ROW()-1`;
- порядок у формі: `Кількість → Ціна → Сума`;
- звичайний розрахунок: `Ціна × Кількість = Сума`;
- режим `⟳ Розрахунок від суми`: `Сума ÷ Кількість = Ціна`;
- у Excel `Сума` залишається формулою `=Pрядок*Qрядок`;
- `Штатна потреба` не перераховується;
- кожен запис `Рух майна` має стабільний послідовний `ID транзакції`: `TX-001`, `TX-002`, …, `TX-999`, `TX-001000`, `TX-001001`; ID не змінюється при редагуванні, переноситься в `Контроль змін`, а старі UUID-ID мігрують у послідовний формат;
- під широкою таблицею додано постійно видимий горизонтальний повзунок прокрутки;
- додано генератор інвентарних номерів: префікс, суфікс, кількість цифр і наступний порядковий номер;
- у формі `Рух майна` біля `Інвентарний номер` є кнопка `Згенерувати`; генератор пропускає вже зайняті номери й збільшує лічильник лише після збереження запису.
- додано окремий розділ `Налаштування`;
- у `Налаштуваннях` додано блок `Комісія`: голова комісії та необмежена кількість членів із можливістю додавання/видалення;
- локально зберігаються реквізити військової частини, командира, начальника служби, начальника ФЕС та параметри нумерації документів у `oblik_settings.json` поруч із програмою;
- блок комісії має голову та необмежену кількість членів у структурі `посада → звання → Ім’я та Прізвище`, кількість членів рахується автоматично;
- додано коефіцієнти індексації за 2023, 2024 і 2025 роки, щоб налаштування відповідали старій структурі `Setting`.

## Технології

- Python
- Flet 1.x — desktop UI
- pandas — обробка та аналіз
- openpyxl — Excel
- PyInstaller через `flet pack` — автономний Windows EXE

## Запуск із Python

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src\main.py
```

## Збірка EXE у Windows

Запустіть:

```bat
build_windows.cmd
```

Готовий файл:

```text
dist\Oblik.exe
```

## GitHub Actions

`.github/workflows/build-windows.yml`:
1. встановлює залежності;
2. запускає smoke-test бізнес-логіки;
3. перевіряє імпорт Flet UI;
4. збирає автономний `Oblik.exe` через `flet pack`;
5. публікує artifact `Oblik-Windows-Flet`.

## Важливо про запаси

Для поштучного майна поточний стан визначається за інвентарним або заводським номером.

Для запасів без унікального номера автоматичне згортання поки навмисно не виконується — спочатку потрібно остаточно зафіксувати правила кількісного приходу, передачі, повернення, списання і залишку.
