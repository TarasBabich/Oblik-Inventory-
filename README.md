# Oblik Inventory

Desktop-програма для обліку необоротних активів і запасів з Excel-сумісною структурою.

## Поточна версія 0.1.0

Реалізовано:
- відкриття існуючої `.xlsx` книги;
- створення нової книги з 5 аркушами;
- перегляд `Штат`, `Рух майна`, `Поточний стан`, `Зведений`, `Контроль змін`;
- додавання, редагування і видалення записів `Рух майна`;
- гнучка логіка: конфлікти не блокують збереження;
- автоматичний журнал `Контроль змін`;
- контроль дублювання за 5 параметрами;
- 5/5 — червоний текст, 4/5 — помаранчевий, 3/5 — жовтий;
- пошук у відкритій таблиці;
- автоматичне формування `Поточний стан` для поштучного майна;
- `Штатна потреба` не перераховується, а переноситься без зміни;
- `Запаси` не зобов'язані мати інвентарний номер.

## Логіка дублювання

Порівнюються:
1. наряд / договір;
2. дата наряду / договору;
3. документ про отримання;
4. дата документа про отримання;
5. інвентарний номер, а за його відсутності — заводський номер.

Збіг одного інвентарного номера в різних операціях не вважається дублем сам по собі.

## Запуск із Python

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src\main.py
```

## Збірка EXE локально у Windows

Запустіть:

```bat
build_windows.cmd
```

Готовий файл буде в `dist\Oblik.exe`.

## GitHub Actions

`.github/workflows/build-windows.yml` автоматично збирає `Oblik.exe` на Windows при pull request або ручному запуску workflow.

## Важливо про поточний стан запасів

Для необоротних активів / поштучного майна програма визначає останній запис за інвентарним або заводським номером.

Для запасів без унікального номера автоматичне згортання поки навмисно не виконується: для нього потрібно окремо зафіксувати правила кількісного приходу, передачі і залишку, щоб не створити помилковий облік.
